# Состав команды и зоны ответственности

### Андрей - Team Lead / Системный аналитик / UI-UX дизайнер
* Координация команды, ведение бэклога спринтов и контроль рамок MVP.
* Проектирование интерактивных макетов интерфейса в Figma (каталог, калькулятор, профиль).
* Моделирование архитектуры процессов (диаграммы BPMN 2.0) и участие в проектировании схемы БД.
* Участие в интеграции фронтенда с бэкендом (согласование контрактов и помощь с API).
* Проведение код-ревью входящих Pull Request в ветку `dev`.

### Владислав - Backend Lead / Архитектор БД
* Проектирование реляционной схемы данных PostgreSQL и сопровождение миграций Alembic.
* Разработка архитектуры серверной части на FastAPI и Pydantic.
* Реализация базовых модулей API (каталог блюд, фильтрация по столовым, профиль).
* Реализация алгоритма подбора рациона с учётом бюджета и целевого КБЖУ.
* Координация совместной бэкенд-разработки с Арсением.

### Арсений - Backend-разработчик / QA & DevOps инженер
* Разработка вспомогательных модулей бэкенда на FastAPI совместно с Владом.
* Генерация и структурирование синтетических наборов данных меню столовых (`data/dishes.csv`, `data/canteens.json`).
* Написание автотестов API (модульные и интеграционные тесты на `pytest`).
* Настройка контейнеризации (Dockerfile, docker-compose) и сопровождение развёртывания на сервере.

### Вениамин - Frontend-разработчик
* Вёрстка страниц и компонентов приложения строго по макетам из Figma от Андрея.
* Обеспечение адаптивности интерфейса (мобильные устройства и десктоп).
* Реализация клиентской логики и подключение к эндпоинтам бэкенда (интеграция REST API).
* Обработка состояний интерфейса (индикаторы загрузки, валидация полей ввода, пустые списки, ошибки сервера).
